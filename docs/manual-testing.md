# 手工验收

测试前确认 VPN、目标服务、远端主机、SSH Agent/Keychain 和 autossh 状态。执行前可用 `ssh remote-host true` 做只读认证检查。

1. **正常连接**：新建远端主机隧道，远端 15432 空闲，点击启动；检查状态变为已连接、autossh/ssh PID 有值、远端监听 TCP 检查为 ok。服务协议需使用实际客户端另行验证。
2. **无监听时启动**：先 `ssh remote-host "ss -ltnp 'sport = :15432'"` 确认输出为空，再启动，确认出现远端监听并且日志无端口冲突。
3. **旧会话占用**：在测试用远端端口保留一个端到端不可达的旧转发，保持本机到目标服务和远端 SSH 可达，再启动配置；确认显示“远端端口冲突”和下次自动重试时间，重试会持续退避，但不反复启动 autossh。释放该测试端口后，不点击“启动”，确认隧道自行恢复；清理按钮仍先展示详情并要求二次确认。
4. **非受管监听 TCP 可达**：保持一个能接受 TCP 但转发到错误目标的测试监听，点击启动；确认显示端口冲突、目标未验证、不新增本 profile 的 autossh，也不显示已连接。HTTPS 场景另外验证错误证书或错误 HTTP 服务不会被 TCP 检查证明健康。
5. **OpenVPN 断开**：隧道建立后断开 VPN；确认 DNS 或目标服务 TCP 检查失败，状态变为 VPN/目标不可达，不连续刷相同错误日志。
6. **VPN 恢复**：恢复 VPN，不点击“启动”；确认已开启“自动重连”的隧道自动重建 autossh，恢复连接。
7. **未启动时 VPN 恢复**：关闭“随应用启动”、开启“自动重连”，先断开 VPN 并打开 AutoSSH Desk；确认初始为“未启动”，手动恢复 VPN 后不点击“启动”，确认 autossh 自动建立隧道。随后点击“停止”，等待一轮监控，确认不会自行重新连接。
8. **SSH 认证失败**：在临时 profile 中使用不存在的 key 或不可用 Agent；确认状态为错误、认证检查失败，进程不持续重启。
9. **目标服务端口不可达**：临时把目标端口改为一个不可达端口，确认 DNS 成功但目标服务 TCP 失败，autossh 不启动。
10. **睡眠唤醒**：连接正常时合盖数分钟再唤醒；确认日志出现系统唤醒诊断，状态重新校验。
11. **应用重启接管**：启动隧道后关闭 AutoSSH Desk 后端，再运行 `./run.sh`；确认 PID 与启动时间能恢复，未启动第二个 autossh。
12. **停止边界**：记录应用启动的 PID 和一个无关 SSH 进程 PID，点击停止；确认只终止本 profile 的进程组，无关 SSH 仍存在。
13. **日志脱敏**：在测试日志副本中加入 `password=test` 和伪私钥块，刷新页面与复制诊断；确认界面和剪贴板不包含原值。
14. **冲突中停止**：冲突等待重试时点击“停止”，释放远端端口并等待一轮监控，确认不会自动启动；再次点击“启动”后才能恢复自动连接。
15. **非受管监听释放**：应用显示非受管监听占用后，停止该测试转发；不点击“启动”，确认应用自动建立自己管理的 autossh。
16. **清理前 TCP 状态变化**：打开冲突清理详情后，让同一远端监听从失败变为可达或从可达变为失败，再确认清理；确认请求被拒绝，会话未被终止。
17. **TCP 可达监听显式清理**：核对唯一 sshd 的精确地址、端口和用途；确认页面不把 TCP 可达称为服务健康，勾选中断该会话全部转发后才能发送 SIGTERM。
18. **SSH 配置隔离**：测试别名中添加额外 RemoteForward 或连接复用配置；确认诊断不创建这些额外监听，受管启动拒绝含额外转发的别名。移除额外转发后受管 SSH 使用独立、非后台持久连接。
19. **SSH 临时握手失败**：在测试环境让 SSH TCP 探测成功，但后续 SSH 会话出现连接重置、超时或无错误输出的非零退出；确认显示重连中且有下次重试时间，而不是永久认证错误。故障消失后不点击“启动”，确认自动恢复；受管 autossh 仍在运行时不得仅因这次探测失败就终止它。确认达到 60 秒退避上限后仍持续重查，手动停止或关闭自动重连后不再自动启动。

20. **通用服务文案**：建立 HTTPS 443 或其他 TCP 服务的测试配置，确认详情、故障提示、新建表单和复制连接参数均使用“目标服务”，不假定 PostgreSQL 或 DBeaver。
21. **监听状态颜色**：受管 SSH 子进程存在、诊断通过并显示已连接时，“远端监听”卡片应为绿色；非受管监听、尚无受管 SSH 子进程或连接未确认时保留警告，不据此宣称目标服务已通过协议验证。
22. **逐页远端指令**：切换两个目标均为 443、远端监听端口不同的测试配置，确认 socat 目的端口、建议回环入口和 hosts 域名同步更新，复制内容与当前页一致。确认命令不自动执行、只监听回环地址、hosts 先备份再编辑；IP 或 localhost 目标不生成 hosts 映射。

清理测试：只在确认唯一 sshd PID、地址和端口完全匹配后操作；任何不确定情况都使用页面给出的手工命令。
